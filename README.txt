GENIE WORKFORCE SOLUTIONS — DEMO-READY WEBSITE
==============================================

This is a static website built with HTML, CSS and vanilla JavaScript only.
No Python, Node.js, npm, frameworks, build step or local server is required.

HOW TO OPEN IT
1. Download Genie-Workforce-Demo-Ready.zip.
2. Right-click the ZIP and select Extract All.
3. Open the extracted Genie-Workforce-Demo-Ready folder.
4. Double-click index.html. It should open directly in Chrome, Edge or Firefox.
5. Keep styles.css, script.js and the assets folder beside index.html.

FILES
index.html   Website page content
styles.css   Responsive design and visual styles
script.js    Mobile navigation, current year and enquiry email behavior
assets/      Logo and locally stored photos

OFFLINE
The page styling, JavaScript and images are local. Internet is not required to
render the website. The enquiry form opens the visitor's default email program;
it does not store submissions or send them to a server.

BEFORE PUBLIC LAUNCH
Confirm pricing, contact details, claims, image permissions and terms. Connect a
real form service/backend if you need to collect enquiries without email software.
